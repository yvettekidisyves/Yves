# HR后勤支持自动化技能包

从需求收集、飞书投票与接龙，到外卖购物车、费用截图和发票整理的通用技能包。采用 **1个总控＋6个子技能**，支持每次更换餐厅、人数、菜品、时段和配送地点。

## 下载与安装

[下载完整技能包 v1.0.0](promotion-support-kit-v1.0.0.zip) · [完整流程SOP](全流程SOP.md) · [验证说明](验证说明.md)

当前以完整ZIP发布；全部技能源文件、脚本、模板及目录结构均在ZIP内。解压后将 `promotion-support-kit/skills/` 下的七个技能文件夹放到所在环境的技能目录，保持相邻关系；Codex常用位置为 `~/.codex/skills/`，实际遵守工作区和宿主规则。已有同名技能先比较和备份。包内README提供完整安装与操作说明。

## 包含哪些技能

| 技能 | 用途 |
|---|---|
| promotion-support | 总控、阶段路由与授权状态 |
| promotion-intake | 需求、日期、预算、地点和执行计划 |
| feishu-meal-collection | 原生飞书投票、接龙、全量需求统计 |
| feishu-meituan-lunch | 实际菜单、规格、购物车差量与核对 |
| coffee-batch-ordering | 完整饮品规格、上午下午和地点分单 |
| order-cost-archive | 正式订单实付、到账退款与截图归档 |
| invoice-reconciliation | 原件、票号去重、费用覆盖与差额 |

示例：`用 $promotion-support 整理本次大促后勤支持，先列执行计划，发布和付款按本次授权。`

## 25分钟目标与验证

每次点餐请求20分钟交购物车核对，留5分钟审核；15分钟预计赶不上提前交接，25分钟报告真实状态。规则检查、等待、认证和断连均计入，不按分单重置。用户明确要求超时继续则继续，并记录实际耗时。25分钟为执行目标，未证明所有真实门店每次都能达标。

39项本地合成行为测试及6个脚本CLI入口已验证。脚本只处理本地文件，不自动发消息、加购或付款；飞书、邮箱和手机操作仍需使用者所在环境的工具与授权。分享包已去除真实群、人员、地址、订单、发票、凭证和个人绝对路径。

ZIP内附逐文件SHA-256清单；这里不包含制作者的私有项目资料。
